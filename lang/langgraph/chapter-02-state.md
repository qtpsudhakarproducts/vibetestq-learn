# Chapter 2 — State: The Shared Memory of Your Graph

---

## The Problem

Your QA workflow has six steps: parse requirements, generate test cases, check quality, get human approval, generate test data, and save output. Each step needs data from previous steps.

Without shared state, you would pass every value through every function signature — a chain of returns that grows unwieldy and breaks every time you add a new step.

**LangGraph solves this with a state object.** Every node reads the full state and returns only what it changed. Nothing else.

---

## What Is State?

**State is the shared clipboard that all nodes in a graph read from and write to.**

Think of a bug triage meeting. The team shares a whiteboard:
- The product manager writes the bug description
- The developer writes their diagnosis
- The QA engineer writes which test case covers it
- The lead writes the priority

Nobody copies the entire whiteboard. Each person reads what they need and adds their contribution. State works the same way.

---

## Defining State with `Annotation`

LangGraph uses `Annotation.Root()` to define the state schema. Each field gets its own `Annotation<Type>()`.

```typescript
import { Annotation } from '@langchain/langgraph';

const QAStateAnnotation = Annotation.Root({
  // Input fields
  requirements: Annotation<string>(),
  
  // Generated by AI nodes
  testCases: Annotation<string[]>(),
  qualityScore: Annotation<number>(),
  
  // Decision fields
  approved: Annotation<boolean>(),
  retryCount: Annotation<number>(),
  
  // Output fields
  finalOutput: Annotation<string>(),
});

// TypeScript type for use in node functions
type QAState = typeof QAStateAnnotation.State;
```

**What this means for testers:** The state definition is the specification of your workflow's data contract. It is the equivalent of defining your test data interface before writing tests.

## Reducers: How State Updates Are Merged

When a node returns an update, LangGraph needs to know **how to merge it into the existing state**. This is controlled by a **reducer**.

### Default reducer — replace the value
```typescript
testCases: Annotation<string[]>(),
```
When a node returns `{ testCases: ['TC-01', 'TC-02'] }`, the existing `testCases` array is **replaced entirely**.

### Append reducer — add to the array
```typescript
import { Annotation } from '@langchain/langgraph';

testCases: Annotation<string[]>({
  reducer: (existing, update) => [...existing, ...update],
  default: () => [],
}),
```
Now when a node returns `{ testCases: ['TC-03'] }`, `TC-03` is **added to** the existing array.

### Custom reducer — your own logic
```typescript
retryCount: Annotation<number>({
  reducer: (existing, update) => existing + update,
  default: () => 0,
}),
```
Returning `{ retryCount: 1 }` adds 1 to the current count rather than replacing it.

## Complete State Example for a QA Review Workflow

```typescript
import 'dotenv/config';
import { Annotation } from '@langchain/langgraph';

// Define a realistic QA workflow state
export const ReviewWorkflowState = Annotation.Root({
  // --- Input ---
  requirements: Annotation<string>(),

  // --- Generated ---
  testCases: Annotation<string[]>({
    reducer: (existing, update) => [...existing, ...update],
    default: () => [],
  }),

  // --- Evaluation ---
  qualityScore: Annotation<number>(),
  qualityFeedback: Annotation<string>(),

  // --- Control flow ---
  retryCount: Annotation<number>({
    reducer: (existing, update) => existing + update,
    default: () => 0,
  }),
  approved: Annotation<boolean>(),

  // --- Output ---
  summary: Annotation<string>(),
});

export type ReviewState = typeof ReviewWorkflowState.State;
```

**The default function** is called when the graph starts. It sets the initial value for the field. Without a default, the field starts as `undefined`.

## How Nodes Update State

A node receives the full current state. It returns an **object with only the fields it changed**. Fields it does not return stay unchanged.

```typescript
import { ChatOpenAI } from '@langchain/openai';

const model = new ChatOpenAI({ model: 'gpt-4o', temperature: 0 });

// This node only updates testCases — everything else stays the same
async function generateTestCasesNode(state: ReviewState) {
  const response = await model.invoke([
    {
      role: 'system',
      content: 'You are a QA engineer. Generate 3 test cases as a numbered list.',
    },
    {
      role: 'user',
      content: `Requirements:\n${state.requirements}`,
    },
  ]);

  const testCasesText = response.content as string;
  const parsed = testCasesText
    .split('\n')
    .filter((line) => /^\d+\./.test(line))
    .map((line) => line.trim());

  return { testCases: parsed }; // only this field changes
}

// This node only updates qualityScore and qualityFeedback
async function evaluateQualityNode(state: ReviewState) {
  const response = await model.invoke([
    {
      role: 'user',
      content: `Rate these test cases from 1-10 and explain briefly:\n${state.testCases.join('\n')}`,
    },
  ]);

  const text = response.content as string;
  const scoreMatch = text.match(/\b([1-9]|10)\b/);
  const score = scoreMatch ? parseInt(scoreMatch[0]) : 5;

  return {
    qualityScore: score,
    qualityFeedback: text,
  };
}
```

## Complete Working Example

```typescript
import 'dotenv/config';
import { StateGraph, END, Annotation } from '@langchain/langgraph';
import { ChatOpenAI } from '@langchain/openai';

const StateSchema = Annotation.Root({
  requirements: Annotation<string>(),
  testCases: Annotation<string[]>({
    reducer: (existing, update) => [...existing, ...update],
    default: () => [],
  }),
  qualityScore: Annotation<number>(),
  qualityFeedback: Annotation<string>(),
});

type State = typeof StateSchema.State;

const model = new ChatOpenAI({ model: 'gpt-4o', temperature: 0 });

async function generateNode(state: State) {
  const response = await model.invoke([
    { role: 'system', content: 'Generate 3 test cases as a numbered list.' },
    { role: 'user', content: state.requirements },
  ]);
  const lines = (response.content as string)
    .split('\n')
    .filter((l) => /^\d+\./.test(l))
    .map((l) => l.trim());
  return { testCases: lines };
}

async function evaluateNode(state: State) {
  const response = await model.invoke([
    {
      role: 'user',
      content: `Rate these 3 test cases from 1-10:\n${state.testCases.join('\n')}`,
    },
  ]);
  const text = response.content as string;
  const match = text.match(/\b([1-9]|10)\b/);
  return {
    qualityScore: match ? parseInt(match[0]) : 5,
    qualityFeedback: text,
  };
}

const graph = new StateGraph(StateSchema)
  .addNode('generate', generateNode)
  .addNode('evaluate', evaluateNode)
  .addEdge('__start__', 'generate')
  .addEdge('generate', 'evaluate')
  .addEdge('evaluate', END);

const app = graph.compile();

const result = await app.invoke({
  requirements: 'User can reset password via email link',
});

console.log('\nTest Cases:');
result.testCases.forEach((tc, i) => console.log(`  ${i + 1}. ${tc}`));
console.log(`\nQuality Score: ${result.qualityScore}/10`);
console.log(`Feedback: ${result.qualityFeedback}`);
```
