## How to Use This Guide

Each file contains real questions asked in actual QA/SDET interviews. Questions progress from basic to complex within each topic. Every question has three answer variants so you can calibrate your response to the role you are targeting.

**Junior answers** demonstrate awareness of the concept, basic syntax knowledge, and an ability to use the tool.

**Lead answers** demonstrate design judgment, trade-off awareness, experience with failures, and team considerations.

**Architect answers** demonstrate system-wide thinking, scalability strategy, integration with SDLC, toolchain decisions, and the ability to drive standards across an organisation.
