## Appendix B: Accessibility Roles Complete Reference

### Common ARIA Roles

**Interactive Elements:**
- `button` - Buttons
- `link` - Links
- `checkbox` - Checkboxes
- `radio` - Radio buttons
- `textbox` - Text inputs
- `searchbox` - Search inputs
- `combobox` - Dropdowns
- `listbox` - List boxes
- `option` - Dropdown options
- `slider` - Range sliders
- `switch` - Toggle switches
- `tab` - Tab buttons
- `menuitem` - Menu items

**Structural Elements:**
- `heading` - Headings (h1-h6)
- `list` - Lists (ul, ol)
- `listitem` - List items (li)
- `table` - Tables
- `row` - Table rows
- `cell` - Table cells
- `columnheader` - Column headers
- `rowheader` - Row headers

**Landmark Roles:**
- `banner` - Header/banner
- `navigation` - Navigation
- `main` - Main content
- `complementary` - Sidebar
- `contentinfo` - Footer
- `search` - Search region
- `form` - Form region

**Dialog Roles:**
- `dialog` - Modal dialogs
- `alertdialog` - Alert dialogs
- `alert` - Alert messages
