- Integrate tests with CI/CD pipelines
- Debug and resolve test failures
- Collaborate with developers on code quality
- Create test data management solutions
- Document testing processes and standards

- 3-5 years of SDET experience
- Strong programming skills in Java or C#
- Experience with automation frameworks
- Knowledge of testing methodologies
- Familiarity with version control and CI/CD
