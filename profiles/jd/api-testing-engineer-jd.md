# API Testing Engineer

## Job Title
SDET - API Testing

## Location
Kolkata, India

## Experience Required
3-5 years

## Key Skills
Postman, RestAssured, Java, Newman, Contract Testing, CI Integration

## Job Description
We are seeking an SDET specializing in API testing to ensure the reliability and performance of our backend services. This role involves automating API tests and integrating them into CI pipelines.

## Responsibilities
- Design and automate API test suites
- Perform functional, performance, and security testing of APIs
- Implement contract and integration testing
- Integrate API tests into CI/CD pipelines
- Collaborate with backend developers on API design
- Analyze test results and provide feedback
- Maintain API test data and environments
- Document API testing processes and standards

## Qualifications
- Bachelor's degree in Computer Science or Engineering
- 3+ years of experience in API testing and automation
- Proficiency in Postman, RestAssured, or similar tools
- Knowledge of REST, GraphQL, and web services
- Experience with Java or other programming languages
- Familiarity with CI/CD tools and version control

- Attractive compensation
- API testing tool subscriptions
- Professional development opportunities
