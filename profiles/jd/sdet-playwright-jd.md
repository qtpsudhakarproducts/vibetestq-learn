## Job Description
We seek an experienced SDET specializing in Playwright to build and maintain automated test suites for our web applications. The role focuses on end-to-end testing, CI integration, and improving test reliability.

## Responsibilities
- Develop and maintain Playwright-based automation frameworks
- Write automated test scripts for UI and API testing
- Integrate tests into CI/CD pipelines using GitHub Actions
- Perform cross-browser and visual regression testing
- Collaborate with developers on testability and code quality
- Analyze test results and debug failures
- Mentor junior team members on automation best practices
- Ensure high test coverage for new features

## Qualifications
- Bachelor's degree in Computer Science or IT
- 3+ years of experience in test automation
- Strong proficiency in Playwright and JavaScript/TypeScript
- Experience with CI/CD tools and version control
- Knowledge of API testing and web technologies
- Familiarity with Agile methodologies
