# Performance Tester

## Job Title
Performance Tester

## Location
Kochi, India

## Experience Required
5-7 years

## Key Skills
JMeter, Gatling, Load Testing, Performance Monitoring, Profiling, Analysis

## Job Description
As a Performance Tester, you will design and execute performance tests to ensure our applications can handle expected loads. This role involves analyzing bottlenecks and recommending optimizations.

## Responsibilities
- Design and execute load, stress, and performance tests
- Analyze test results and identify performance bottlenecks
- Create performance test plans and scripts
- Monitor application performance in production
- Collaborate with developers to implement fixes
- Generate performance reports and recommendations
- Maintain performance testing environments
- Stay updated with performance testing tools and techniques

## Qualifications
- Bachelor's degree in Computer Science or Engineering
- 5+ years of experience in performance testing
- Proficiency in JMeter, Gatling, or similar tools
- Knowledge of monitoring and profiling tools
- Understanding of web technologies and databases
- Strong analytical and problem-solving skills

## Benefits
- Competitive compensation package
- Professional certification support
- Health insurance coverage
- Career advancement opportunities
