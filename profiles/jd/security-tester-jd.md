# Security Tester

## Job Title
Security Tester

## Location
Chandigarh, India

## Experience Required
3-5 years

## Key Skills
OWASP, Penetration Testing, Burp Suite, Security Scanning, Secure Coding, Vulnerability Assessment

## Job Description
We need a Security Tester to assess and improve the security posture of our applications. This role involves conducting security tests and ensuring compliance with security standards.

## Responsibilities
- Perform web application security assessments
- Conduct penetration testing and vulnerability scans
- Identify and report security vulnerabilities
- Validate security fixes and patches
- Integrate security tests into CI/CD pipelines
- Provide security recommendations and best practices
- Collaborate with development teams on secure coding
- Stay updated with latest security threats and trends

## Qualifications
- Bachelor's degree in Information Security or Computer Science
- 3+ years of experience in application security testing
- Knowledge of OWASP Top 10 and security testing methodologies
- Proficiency in tools like Burp Suite, OWASP ZAP
- Understanding of web technologies and protocols
- Certification in security testing (CEH, OSCP) is preferred

## Benefits
- Competitive salary
- Security certification reimbursements
- Comprehensive benefits package
- Opportunities for professional growth
