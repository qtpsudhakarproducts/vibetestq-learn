# Mid-level Automation Engineer

## Job Title
Mid-level Automation Engineer

## Location
Hyderabad, India

## Experience Required
3-5 years

## Key Skills/Technologies
Selenium, Playwright, JavaScript/TypeScript, Cypress, TestNG/Jest, CI/CD, GitHub Actions, API Testing

## Job Description
As a Mid-level Automation Engineer, you will design and maintain automated test frameworks for our applications. This role focuses on improving test efficiency and coverage.

## Responsibilities
- Develop and maintain automation test suites
- Implement frameworks using Selenium, Playwright, or Cypress
- Integrate automated tests into CI/CD pipelines
- Perform cross-browser and cross-platform testing
- Create reusable test utilities and libraries
- Analyze test results and improve reliability
- Collaborate with developers on test-driven development
- Train team members on automation best practices

## Qualifications
- Bachelor's degree in Computer Science or IT
- 3-5 years of test automation experience
- Proficiency in at least one automation tool
- Knowledge of programming languages and frameworks
- Experience with CI/CD tools
- Strong analytical and problem-solving skills
