# Junior SDET

## Job Title
Junior SDET

## Location
Pune, India

## Experience Required
0-2 years

## Key Skills/Technologies
Selenium, Java/Python, TestNG/Pytest, Git, Basic Automation, API Testing, CI/CD Basics

## Job Description
Join our team as a Junior SDET to learn and apply software development and testing skills. This role involves writing automated tests, debugging code, and ensuring software reliability.

## Responsibilities
- Write and execute automated test scripts using Selenium
- Learn programming languages like Java or Python
- Perform API testing using tools like Postman
- Integrate tests into basic CI pipelines
- Debug and fix test failures
- Collaborate with developers on code quality
- Document test automation processes
- Participate in code reviews and pair programming

## Qualifications
- Bachelor's degree in Computer Science or IT
- Fresh graduate with programming knowledge
- Basic understanding of automation testing
- Familiarity with version control (Git)
- Strong problem-solving skills
- Enthusiasm for learning new technologies

## Benefits
- Competitive salary
- Mentorship program
- Certification support
- Flexible working environment
- Growth into senior roles
