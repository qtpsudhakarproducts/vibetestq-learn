# AI Test Analyst

Illustrative learning example; not a real candidate. Reviewed October 4, 2026.

**Example experience:** 2 years

**Focus:** Manual AI output review and rubric use

## Professional summary

- Building practical experience in manual ai output review and rubric use.
- Demonstrates rubric-based review, edge-case selection, and clear failure descriptions with a small evaluation dataset.
- Explains test choices, findings, and limitations with reproducible evidence and clear collaboration.

## Responsibilities

- Works on a defined feature or test slice with review. Builds fundamentals, reports evidence clearly, and asks for help when expected behavior is unclear.
- Define expected behavior using examples and a documented rubric.
- Keep evaluation inputs and model configuration versioned.
- Separate application defects, data issues, and unacceptable model behavior.

## Core skills

- Manual evaluation and clear written findings
- Evaluation datasets and grading rubrics
- Expected behavior and failure analysis
- Data quality and reproducible experiments
- Model or prompt regression comparison
- Clear evaluation reports

## Optional / role-dependent

- An evaluation framework appropriate to the project
- Retrieval or agent workflow specialization
- Statistical analysis and evaluation calibration
- Python scripting as a next learning step
