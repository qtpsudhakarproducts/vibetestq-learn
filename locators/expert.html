Section 1 — XPath Functions

Master the most powerful XPath string functions: normalize-space() to trim whitespace, string-length() to filter by value length, translate() for case-insensitive matching, and concat() for value composition.

normalize-space(text())="Label" trims leading/trailing whitespace AND collapses internal spaces — critical for multi-line labels or server-rendered HTML that adds extra indentation.
Exercise 40Expert
normalize-space() — Trim Whitespace in Labels
Three form labels have inconsistent whitespace. Select the label whose trimmed text is exactly "Email Address" using normalize-space().
Expected: 1 element
Live HTML — Sandbox
CSS N/A — CSS cannot inspect text content.
XPath
normalize-space(text()) trims leading/trailing whitespace AND collapses multiple spaces into one before comparing. This is more robust than text()= for whitespace-heavy HTML.
XPath: //label[normalize-space(text())="Email Address"]

Case-Insensitive Match — translate()
Status chips have mixed-case text: "ACTIVE", "Active", "active". Select all chips whose text is "active" in any casing — there are 3.
Expected: 3 elements
Live HTML — Sandbox
ACTIVE Inactive Active PENDING active
CSS N/A — CSS cannot perform case-insensitive text comparison.
XPath
translate(text(), "ABC...Z", "abc...z") converts the text to lowercase before comparing. XPath 1.0 has no lower-case() function, so translate() is the standard workaround.
XPath: //span[translate(normalize-space(text()),"ABCDEFGHIJKLMNOPQRSTUVWXYZ","abcdefghijklmnopqrstuvwxyz")="active"]

Section 2 — Nested Contexts

Scope selectors precisely inside nested components: cards inside cards, tabs with panels, accordions, and wizard steps. Avoid false matches in sibling components.

In test automation, a selector that accidentally matches the wrong component causes flaky tests. Always use a unique ancestor ID or class to scope your path. Prefer IDs when available — they're the most stable anchors.

Section 3 — Position Logic

Complex positional patterns that combine multiple predicates with position, select every Nth item from the end, or use modulus arithmetic inside XPath predicates.

In CSS, :nth-child(3n+1) matches items 1, 4, 7… In XPath 1.0, use position() mod 3 = 1 inside the predicate. Both describe the same pattern but the syntax differs significantly.

Section 4 — Real-World Patterns

Patterns taken directly from production test suites: dynamic IDs, breadcrumb position, form validation errors near specific fields, and multi-step wizard progress.

In real apps, IDs like input_7a3b are generated and unstable. Always prefer stable anchors: data-testid, aria-label, role, or positional XPath relative to a stable parent. This section trains you to work around instability.
