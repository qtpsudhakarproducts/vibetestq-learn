XPath: //input[@type="password"]  or  //input[@id="sb1-pass"]

Select All Warning Buttons
Five buttons are shown with different colour styles. Select only the amber warning buttons — there are 2 of them.
Expected: 2 elements
Live HTML — Sandbox
CSS Selector
XPath
Each button has a class like btn-primary, btn-warning, etc. Target the shared class of the amber buttons. In XPath, use contains(@class, '...') when an element can have multiple classes.
CSS:  .btn-warning  or  button.btn-warning
XPath: //button[contains(@class,"btn-warning")]

CSS:  input[required]
XPath: //input[@required]

Descendant — Links Inside the Nav
There are links both inside and outside the navigation bar. Select only the 4 links inside the nav — not the paragraph link below it.
Expected: 4 elements
Live HTML — Sandbox

CSS Selector
XPath
A descendant selector matches elements anywhere inside an ancestor. In CSS use a space: nav a. In XPath use // inside a path: //nav//a. This reaches links nested inside the dropdown div too.
CSS:  nav a  or  .sb-nav a
XPath: //nav//a  or  //*[contains(@class,"sb-nav")]//a

CSS Selector

CSS Selector
XPath
CSS: chain two class selectors with no space between them — .alert.alert-danger means "has both classes simultaneously". XPath: contains(@class,"alert-danger") matches any element whose class attribute contains that string.
CSS:  .alert.alert-danger
XPath: //*[contains(@class,"alert-danger")]

Sibling / Axes — Input After a Label
A form has three label–input pairs. Select the input that immediately follows the "Email" label using a sibling relationship — not the input's own id.
Expected: 1 element
Live HTML — Sandbox
CSS Selector
XPath
CSS: the + combinator selects the immediately following sibling. Look for the label whose for attribute says sb8-email. XPath: use the following-sibling:: axis from that label and take the first input in that axis.
CSS:  label[for="sb8-email"] + input
XPath: //label[@for="sb8-email"]/following-sibling::input[1]
