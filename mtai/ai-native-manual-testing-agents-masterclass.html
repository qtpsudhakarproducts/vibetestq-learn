Program Overview

This course is designed for manual testers to transform their daily workflow using **off-the-shelf AI assistants and agents**. You will not be coding or developing agents; instead, you will master **leveraging** existing tools like MCP servers, AI IDEs, and Browser Agents to 10X your productivity in test design, data management, and execution.

Day 1: AI Foundations & Professional Prompting
Morning: The AI-Native Tester Mindset Session 1 (4 hrs)
  • GenAI Essentials: Using ChatGPT, Claude, and Gemini for QA analysis.
  • Professional Prompting: QA-specific Prompt Engineering (Zero-shot to Chain-of-Thought).
  • Requirements Analysis: Leveraging AI to find gaps in PRDs and User Stories.
  • Risk Assessment: Using AI to prioritize high-risk application areas.
  • Security & Privacy: Best practices for using GenAI in corporate environments.
Practice: Analyze a complex feature document and generate a "Gaps & Risks" report using professional prompting.
Afternoon: AI-Driven Test Design & MCP Basics Session 2 (4 hrs)
  • Scenario & Gherkin: Generating Happy Path & Edge cases with AI.
  • Visual Test Design: Using AI Vision to create test cases from screenshots.
  • Introduction to MCP: Using Claude Desktop with claude_desktop_config.json.
  • Accessing MCPs: Connecting to available marketplace MCP servers.
  • Jira MCP: Leveraging the Jira MCP server to read stories directly in Claude.
Practice: Setup Claude Desktop with Jira MCP and generate a test suite for an assigned Jira ticket.
Day 2: AI IDEs & Browser Agents for QA
Morning: Using AI IDEs for Manual Testing Session 3 (4 hrs)
  • AI IDE Ecosystem: Introduction to **Cursor** and VS Code AI for manual testers.
  • Project Context: Leveraging "Codebase Indexing" to write accurate test cases.
  • Asset Generation: Creating Test Plans and Markdown docs directly in the IDE.
  • Standardization: Using AI IDE Agents to rewrite and clean up old test artifacts.
  • Context-Aware Designing: Writing tests while the AI "reads" the application code.
Practice: Use an AI IDE Agent (like Cursor) to generate a standardized test suite based on a local folder of features.
Afternoon: Leveraging Browser Automation Agents Session 4 (4 hrs)
  • Browser Agents: Using **Comet** and **Claude Chrome Plugin** for UI interaction.
  • Autonomous Navigation: Instructing agents to perform multi-step user journeys.
  • Verification: Using agents to check for UI changes, broken links, and functional errors.
  • Vibe Exploratory Testing: Using agentic assistants to explore "unhappy paths."
  • Agentic Debugging: Prompting agents to identify root causes of UI failures.
Practice: Use the Claude Chrome Plugin or Comet to autonomously execute a "Checkout Flow" validation on a web app.
Day 3: Advanced Leveraging & Capstone
Morning: Advanced MCP & Utility Assistants Session 5 (4 hrs)
  • Playwright MCP Server: Controlling the browser directly from the Claude Chat interface.
  • Vibium & Data MCPs: Leveraging specialized servers for fetching synthetic test data.
  • Orchestration: Using multiple MCPs (Jira + Playwright) for "Requirement to Execution" flow.
  • Intelligent Execution: Using AI to analyze logs and network traffic during manual testing.
  • Bug Reporting: Leveraging AI to generate polished, documented bug reports in Jira.
Practice: Perform a "Connect the Dots" lab: Fetch a Jira ticket via MCP, verify it via Playwright MCP, and log a bug via AI.
Afternoon: The Capstone - Agent-Augmented QA Cycle Session 6 (4 hrs)
  • Synthetic User Personas: Using AI agents to simulate different user behaviors.
  • Daily Status & Metrics: Using AI to summarize testing progress and quality trends.
  • Continuous Testing: Planning your daily routine with AI "Assistants."
  • Final Capstone Project: Perform a full cycle (Requirement -> Test Design -> Data -> Execution -> Bug Report) using the AI Toolkit.
  • Future Readiness: Adapting to the evolving landscape of Agentic Software Testing.
Capstone Lab: Deliver a full Quality Report for a new application feature using ONLY AI-augmented tools.
