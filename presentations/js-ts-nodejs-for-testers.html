PART 1

Core JavaScript Essentials

1. Variables & Data Types

Variable Declarations

  • const: For values that NEVER change (Default choice)
  • let: For values that MAY change (Loops, counters)
  • var: Old way (Avoid due to scope issues)

Primitive Types

  • String: "Hello World"
  • Number: 10, 3.14
  • Boolean: true / false
  • Null/Undefined: Empty values

2. Operators & Decisions

Logical Comparison

  • === : Strict equality (Checks value AND type)
  • && : AND (Both must be true)
  • || : OR (At least one must be true)
// The Ternary Operator
const status =
  age >= 18 ? "Pass" : "Fail";

Always use === to avoid unexpected bugs in assertions.

3. Control Flow & Decisions

If vs Switch

If/Else: Best for complex logic, ranges (e.g., age > 18), or multiple different variables.

Switch: Best for choosing from many fixed values of a single variable (e.g., Status: PENDING, PASS, FAIL).

The 3 Essential Loops

  • Index Based: for(i=0; i<n; i++) - Exact control over iteration.
  • Array Based: for...of - Best for UI Lists or results.
  • Object Based: for...in - Iterating over property keys.
// Object based loop example
for (const key in config) { console.log(config[key]); }

4. Functions: When to use what?

Standard Function

Best for Methods in Classes or when you need this context.

function login() { ... }

Arrow Function

Best for Anonymous callbacks (e.g. within map/filter) or simple logic.

const login = () => { ... }

5. Arrays & Objects

Arrays (Lists)

Store test data or locator results.

  • map(): Transform items
  • filter(): Select specific items
  • find(): Get one item

Objects (Data)

Key-value pairs for configuration.

const config = {
  env: 'QA',
  headless: true
};

6. Modern Syntaxes

Destructuring

Extract values easily from objects/arrays.

const { username, pwd } = userData;

Template Strings

Embed variables inside strings using backticks.

console.log(`Testing on ${env}`);

7. Asynchronous JS (Callbacks)

The Foundation

A callback is a function passed as an argument to be executed later.

  • Used extensively in older Node.js libraries.
  • Can lead to "Callback Hell" if nesting is too deep.
  • Know it to recognize it, but use Promises instead.

8. Promises

Represents a value available in the future.

Pending Fulfilled Rejected
  • .then() : Runs on success
  • .catch() : Runs on failure
  • .finally() : Runs always (Cleanup)

9. async / await

The Gold Standard for Modern Automation

async function test() {
  try {
    await page.goto(url);
  } catch (err) {
    console.error(err);
  }
}

Pauses execution until the Promise settles. Makes code look synchronous!

10. Modules & Classes

Modules

import and export to share code across files (Page Objects, Utils).

Classes

The blueprint for Page Objects. Use this to refer to properties.

PART 2

TypeScript: The Safety Shield

Why TypeScript?

JS + Type Safety = Robust Tests

Bug Prevention

Detect errors like "passing string to number" while writing code.

Intellisense

Get perfect auto-complete suggestions for your custom framework functions.

11. TS Types & Interfaces

Basic Types

  • string, number
  • boolean, void
  • unknown (Safer than any)

Interfaces

Define the "Shape" of test data objects.

interface User {
  id: number;
  name: string;
  email?: string; // Optional
}

12. Union Types & Enums

Union Types

A variable can be one of many types.

type Status = 'pass' | 'fail';

Enums

Fixed set of named constants.

enum Env { QA, DEV, PROD }

13. Advanced TS Basics

Generics

Reusable code that works with different types dynamically.

Utility Types

  • Partial<T>: All fields optional
  • Pick<T, K>: Select specific fields
  • Omit<T, K>: Remove fields

PART 3

Node.js & Project Setup

14. Project Structure

Structure

  • ?? node_modules (Ext libraries)
  • ?? package.json (The Heart)
  • ?? playwright.config.ts
  • ?? tests (Logic)

package.json

  • Define Meta-data
  • Manage Dependencies
  • Create custom scripts

15. npm: The Package Manager

Essential Commands

  • npm init -y: Fast setup
  • npm install: Get all libs
  • npm run test: Execute
  • npm install -D: Dev tools
  • npm list: Check versions
  • npm uninstall: Cleanup

16. Node.js Core Modules

process

Env variables, platform info.

path

Cross-OS file path handling.

fs (File System)

Read/Write test data files (JSON/CSV).

os

System memory & CPU details.

17. Exception Handling

Don't let your tests crash silently!

try {
  // Perform Action
} catch (error) {
  // Take Screenshot / Log
} finally {
  // Close DB/Cleanup
}
  • Prevents build failures on minor errors.
  • Enables meaningful error messages.
  • Ensures cleanup happens always.
