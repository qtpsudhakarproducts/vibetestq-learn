DAY 22

GitHub Actions Pipeline

Automate every push. Never let a breaking change reach main.

Core Practice

  1. Create .github/workflows/playwright.yml
  2. Configure triggers on push and pull_request
  3. Install browsers with playwright install --with-deps
  4. Upload HTML reports and traces as artifacts
DAY 23

Docker & Containers

Run tests in identical environments everywhere. No more "works on my machine".
  • Write a Dockerfile based on playwright-official
  • Setup docker-compose.yml for local runs
  • Run headless tests inside a Linux container
DAY 24

Parallel & Sharding

Cut execution time from minutes to seconds with smart distribution.
  • Set fullyParallel: true in config
  • Experiment with --shard=1/4 commands
  • Merge shard reports using playwright merge-reports
  • Monitor worker efficiency in HTML report
DAY 25

Enterprise Pipelines

Deliver into Jenkins and Azure DevOps. Industry standard workflows.
  1. Create Jenkinsfile with JUnit reporting
  2. Setup azure-pipelines.yml workflow
  3. Configure parameterised builds for specific tags
DAY 26

Visual & Accessibility

Catch what functional tests miss. Pixels and ARIA matter.
  1. Implement toHaveScreenshot() for regression
  2. Mask dynamic content during visual comparison
  3. Integrate @axe-core/playwright for A11y audits
  4. Fail builds on critical WCAG violations
DAY 27

page.evaluate()

Reach inside the browser. Execute JS in the page context.
  • Read computed styles and internal JS state
  • Manipulate localStorage directly
  • Expose Node.js functions to the browser
DAY 28

Semantic & AI Locators

Transition to the intelligent layer of Playwright.
  • Use page.accessibility.snapshot() to see what AI sees
  • Refactor to 100% semantic locators (Role, Label, Text)
  • Experiment with getByAI() experimental features
